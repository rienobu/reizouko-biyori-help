# reizouko-biyori-help
冷蔵庫日和のサポート・プライバシーポリシー

このリポジトリは、冷蔵庫日和の案内ページを GitHub Pages で公開するためのものです。

- [プライバシーポリシー](privacy.html) — 端末内で扱うデータ、権限、保存と削除の方法
- [使い方・サポート](support.html) — 登録や通知、データ復旧の手順、よくある質問と問い合わせ案内

両ページは共通の `help.css` を使用します。公開元はリポジトリのルートを想定しています。

問い合わせ先は準備中です。App Store Connect に登録する前に、実際に連絡できる窓口を掲載してください。
